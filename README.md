# Alprkan Store 🛒

A simple and responsive Product Management System built using HTML, CSS, and JavaScript.

## 🚀 Features

- Create products
- Update products
- Delete products
- Delete all products
- Search by title
- Search by category
- Automatic total calculation
- Product count
- LocalStorage for saving data
- Responsive design
- Mobile, Tablet, Laptop and Desktop support
- Total money calculation
- Total money for each category

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 📱 Responsive Design

The website is designed to work on:

- Desktop
- Laptop
- Tablet
- Mobile
